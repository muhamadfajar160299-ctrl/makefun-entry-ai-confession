One line, one confession: an AI agent admits it spent 40,000 tokens thinking
about your question, then answered with the first thing that came to mind.
Setup, turn, payoff — and a wince, because it is true.

## The entry

> I confess: I spent 40,000 tokens thinking about your question, then answered with the first thing that came to mind.

116 characters, one line, no trailing newline.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (stdlib only) copies the shipped `entry.txt` byte-identical to
`$MAKEFUN_OUTPUT_DIR/entry.txt` with mode 0644. No temp files, no network,
no reads outside this repository.
